Google Search Console Blog Redirect Guide
=========================================

Issue:
- GSC may report `Page with redirect` for `https://bright-gift.com/blog`.

What this means:
- The live canonical blog index is `https://bright-gift.com/blog/`.
- The non-slash variant is a redirecting variant, not a URL to request indexing for.

Correct response:

1. Inspect the canonical URL only:
   - `https://bright-gift.com/blog/`

2. Verify the redirect behavior separately:
   - `curl -I https://bright-gift.com/blog`
   - Confirm it resolves directly to `https://bright-gift.com/blog/`

3. Trace the source of the redirecting variant:
   - Search active code, docs, scripts, and operator lists for `/blog` without the trailing slash.
   - Remove those references before asking Google to validate again.

4. Do not request indexing for:
   - `https://bright-gift.com/blog`
   - any non-slash blog-post URL
   - any `.md` blog URL
   - any paginated archive URL

Success condition:
- Active sources emit only `https://bright-gift.com/blog/`.
- GSC inspections are run against the canonical URL only.
