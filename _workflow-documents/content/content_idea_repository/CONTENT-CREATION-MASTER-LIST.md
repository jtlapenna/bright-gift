### Content Guidelines (MUST FOLLOW)

#### Writing Style
- **Clear, simple, spartan writing** (per user memory)
- **Short, impactful sentences** in active voice
- **Direct address** using "you" and "your"
- **Bullet point lists** where appropriate
- **Avoid:** em dashes, semicolons, markdown formatting in content, asterisks, hashtags, emojis, metaphors, clichés, generalizations
- **Avoid filler words:** can, may, just, very, really, literally, actually
- **Friendly, conversational tone** (not robotic)

#### SEO Requirements
- **Word count:** 1,200-1,500 words minimum
- **Gift ideas:** Around 20 products with detailed descriptions
- **Primary keyword:** In title, first paragraph, 2+ H2 headings
- **Secondary keywords:** In H2/H3 headings naturally
- **Keyword density:** 1-2% for primary, 0.5-1% for secondary
- **Internal links:** 5-10 links to related posts
- **External links:** 3-5 authoritative sources
- **Image alt text:** Include primary keyword in main image

#### Affiliate Products
- **CRITICAL:** All products MUST come from `src/data/productLibrary.ts`
- If product doesn't exist in library, ADD IT FIRST
- Do NOT use products outside the library
- Include Amazon affiliate links where appropriate
- Disclose affiliate relationships

#### Images
- **Banner image:** 1200x630px, SEO-optimized filename
- **Social image:** 1200x630px for social sharing
- **OG image:** 1200x630px for Open Graph
- **Alt text:** Descriptive with primary keyword
- **NO TEXT ON IMAGES** (per brand guidelines)
- Images must match blog post slug

- Link FROM new post TO 3-5 existing posts
- Link FROM 5-10 existing posts TO new post (after publishing)
- Use keyword-rich anchor text
- Link to homepage, category pages, related guides
