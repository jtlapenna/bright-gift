# Image Prompts: Personalized Gifts for Kids

**Post:** `src/content/blog/personalized-gifts-for-kids.md`  
**Use with:** [10_IMAGE_STYLE_GUIDE.md](../INSTRUCTIONS/10_IMAGE_STYLE_GUIDE.md)

**Specs:** Banner and OG both 16:9, 1200px width minimum. No text, logos, or watermarks.

---

## Banner image (16:9, wide horizontal)

Use for in-post banner and any wide hero. Dynamic composition with multiple elements.

```
A cozy reading nook scene with an open personalized storybook (soft 3D illustration of a book showing a child character), a small name puzzle, and a soft blanket or keepsake item arranged in a flowing, organic manner at varying depths. Stylized hands or a gentle silhouette suggest a child or parent enjoying the moment. Soft sparkles or stars near the book. Smooth gradient background transitioning from teal to soft coral-orange with subtle abstract shapes (small circles, dots) in complementary tones. Modern flat illustration with soft 3D-style characters and objects, combined with subtle 2D decorative elements. Use warm, vibrant pastels (teal #00A99D, coral-orange #FF6B35, sunshine yellow #FFD700). Rounded edges, soft shadows under objects, matte surfaces. Layout must be clean and giftable, with balanced negative space and minimal visual clutter. The tone should feel cheerful, light, editorial, and creative — never realistic or photorealistic. 16:9 aspect ratio, 1200px width minimum.
```

---

## OG image (16:9, centered, single focal point)

Use for Open Graph / social share. One strong focal point.

```
Centered composition featuring a single open personalized children's storybook as the main subject, with soft light and a hint of a name puzzle or blanket in the background. Gentle sparkles or curved lines around the book. Smooth gradient background (teal to soft coral) with subtle abstract elements. Modern flat illustration with soft 3D-style objects, combined with subtle 2D decorative elements. Use warm, vibrant pastels (teal #00A99D, coral-orange #FF6B35, sunshine yellow #FFD700). Rounded edges, soft shadows, matte surfaces. Layout must be clean and giftable, with balanced negative space and minimal visual clutter. The tone should feel cheerful, light, editorial, and creative — never realistic or photorealistic. 16:9 aspect ratio, 1200px width minimum.
```

---

## Quality checklist (from style guide)

- [ ] Modern flat illustration with soft 3D elements
- [ ] Teal, coral-orange, sunshine yellow palette
- [ ] Dynamic (banner) / centered focal (OG) composition
- [ ] Rounded edges and soft shadows
- [ ] Gradient background, no text/logos
- [ ] Conceptual scene (reading nook, storybook as hero), not product flat-lay
- [ ] 16:9, 1200px wide
