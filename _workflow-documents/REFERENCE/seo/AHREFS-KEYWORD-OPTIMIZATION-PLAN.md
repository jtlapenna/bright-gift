## Phase 7: Strategic Keyword Placement

### On-Page SEO Optimization

For each post, ensure keywords appear in:

1. **Title Tag** - Primary keyword at the beginning
2. **Meta Description** - Primary + secondary keywords
3. **H1** - Primary keyword (naturally integrated)
4. **First Paragraph** - Primary keyword within first 100 words
5. **H2 Headings** - Secondary keywords (2-3 H2s)
6. **H3 Headings** - Long-tail keywords (3-5 H3s)
7. **Image Alt Text** - Primary keyword in main image, variations in others
8. **URL Slug** - Primary keyword (lowercase, hyphens)
9. **Internal Links** - Anchor text with keywords
10. **FAQ Section** - Question-based keywords

### Keyword Density Guidelines

- **Primary Keyword:** 1-2% density (10-20 times in 2,000-word post)
- **Secondary Keywords:** 0.5-1% density (5-10 times)
- **Long-tail Keywords:** Natural integration (3-5 times)
- **Avoid:** Keyword stuffing, unnatural repetition
