## Common Issues Across All Pages

### Images
- [ ] Banner images too large (need compression)
- [ ] Images not in WebP format
- [ ] Missing lazy loading attributes
- [ ] Missing width/height attributes

### CSS/JavaScript
- [ ] Render-blocking resources
- [ ] Unused CSS
- [ ] Large JavaScript bundles

### Core Web Vitals
- [ ] LCP (Largest Contentful Paint)
- [ ] FID (First Input Delay)
- [ ] CLS (Cumulative Layout Shift)

---

## Action Plan

### Immediate Fixes (Do First)
1. **Compress all banner images** to < 200KB
2. **Convert images to WebP** format
3. **Add lazy loading** to all images
4. **Add width/height** attributes to prevent CLS

### Medium Priority
1. Optimize CSS delivery
2. Defer non-critical JavaScript
3. Enable browser caching
4. Minimize render-blocking resources

### Low Priority
1. Implement CDN for static assets
2. Enable HTTP/2
3. Optimize font loading

## Testing Instructions

**To test each page:**
1. Go to https://pagespeed.web.dev/
2. Enter the full URL
3. Click "Analyze"
4. Record scores for Mobile and Desktop
5. Note specific issues in "Opportunities" and "Diagnostics"
6. Screenshot results for reference

**Focus on:**
- Performance score (most important)
- Core Web Vitals (LCP, FID, CLS)
- Image optimization opportunities
- Render-blocking resources
