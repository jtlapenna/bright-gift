### PRIORITY 3: Fix Duplicate URL Issues (Week 1)

#### Action 3.1: Update All Internal Links
**Goal:** Ensure all internal links use trailing slash version

**Implementation:**
Run a script to find and fix all internal links:

```bash
# Find all internal links without trailing slashes
grep -r 'href="/blog/[^"]*[^/]"' src/content/blog/
```

**Expected Impact:** Consolidate SEO authority to one URL

#### Action 3.2: Add Canonical Tags to All Posts
**Goal:** Tell Google which version is the "real" one

**Implementation:**
Ensure every blog post has:
```html
<link rel="canonical" href="https://bright-gift.com/blog/post-slug/" />
```
