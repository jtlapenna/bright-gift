# Frontmatter Standards Documentation

## Overview

This folder contains comprehensive documentation for frontmatter standards across the multi-tenant blog system, designed to help agents create consistent, SEO-optimized content for multiple sites.

## Contents

### `frontmatter-standards-guide.md`
**Comprehensive guide covering:**
- Basic frontmatter structure and required fields
- Content categorization and target audience
- SEO optimization and meta data
- Image management and specifications
- Social media integration
- Affiliate integration requirements
- Analytics and performance tracking
- Multi-site configuration
- Validation and quality control
- Best practices and examples
 - Dashboard fields: wordCount, readTime, seoScore, readabilityScore
 - Workflow fields: siteId, postId, workflowId, generatedAt, lastUpdated
 - Affiliates data model: affiliatePlatforms (counts), affiliateLinks (list)

 - Dashboard readiness checklist (analytics, workflow, affiliates)
